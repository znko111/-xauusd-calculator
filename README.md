# XAUUSD Lot Calculator

Simple web calculator for gold (XAUUSD) position sizing based on account balance, risk %, and stop-loss distance.

## Usage
Open `index.html` in any browser, or visit the GitHub Pages link.

## Formula
- Risk amount = balance × risk %
- Lot size = risk amount ÷ (stop distance in $ × 100)

Assumes 1 lot = 100 oz. Verify your broker's contract size.
